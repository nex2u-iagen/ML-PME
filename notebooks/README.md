produção.

## 📌 Regras

- Notebook não é fonte de verdade; a lógica consolidada deve ir para `src/`.
- Não versione dados sensíveis nem saídas grandes.
- Fixe a semente aleatória e documente as conclusões.
- Ao promover um experimento, crie teste em `testes/` e README no módulo de destino.
