Ciclo CRISP-DM

Fase 01: Compreensão do Negócio

Extração de requisitos e entendimento do domínio

Fase 02: Compreensão dos Dados

Análise exploratória e raio-x empresarial

Fase 03: Preparação dos Dados

Engenharia de features, ABT, dados para BI e ML

Fase 04: Modelagem

Fabricação de modelos, comparação e otimização

Fase 05: Avaliação

Pódio Top 3, XAI/SHAP, alinhamento de custos, governança

Fase 06: Implantação

Persistência, segurança JWT, contratos, motor de inferência

Frontend Operacional (Streamlit)

Interface Web

Permite operar e auditar cada etapa do CRISP-DM

  • Autenticação JWT via API
  • Execução de fases 01-05 via subprocess
  • Inferência individual via API FastAPI (Fase 06)
  • Validação SHA-256 de artefatos
  • Dashboard de saúde do modelo

Arquitetura Híbrida

subprocess (Fases 01-05) + FastAPI (Fase 06)

Execução local via streamlit run app_streamlit.py
